# Responsive Landing Page

A modern and responsive landing page created as part of a web development project. The website is designed to provide a clean user interface and a smooth experience across desktop, tablet, and mobile devices.

## Features

- Responsive design for different screen sizes
- Fixed navigation menu
- Interactive navigation links
- Hover effects
- Navigation styling changes when scrolling
- Clean and modern user interface
- Mobile-friendly layout
- Attractive hero section
- Structured sections for website content

## Technologies Used

- HTML5
- CSS3
- JavaScript
